# Project skills

Each subdirectory holds a `SKILL.md` for a workflow that applies to this repository. Skills are installed/updated via `npx skills add spenserhale/skills@<skill>` and pinned by `skills-lock.json`.

- `wordpress-cli/`: WP-CLI (`wp`) reference for managing the test site and plugin.
- `wp-vip-cli/`: VIP-CLI for WordPress VIP local dev environments and remote commands.
- `wordpress-performance/`: server-side WordPress performance — hook wiring rules, measurement workflow. Its wiring rules (lazy static callbacks, no I/O in constructors) are binding for this plugin's code.
